# Forex

A personal London/NY-overlap trading dashboard ("TruLux Analytics"). Claude updates it every trading morning with evidence-graded break-and-retest setups on the 7 majors.

## What's here
- `strategy/RULES.md`: the trading rules every setup is graded against (grades, R:R, risk, news filter).
- `strategy/patterns.md`: the 7-pattern library.
- `reference/`: the design references the dashboard is modeled on.

The dashboard itself and the daily routines are still being built.
